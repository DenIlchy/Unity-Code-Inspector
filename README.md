# Unity Code Inspector

Development repository for **Code Inspector**, a Unity 6 editor package that
maps scripts and scenes as an interactive graph — script connections, events,
triggers, live runtime activity and parameter tweaking.

## Install

Add via Unity Package Manager → `+` → **Add package from git URL…**:

```
https://github.com/<github-user>/Unity-Code-Inspector.git?path=/Packages/com.denid.codeinspector
```

## Repository layout

- `Packages/com.denid.codeinspector` — the package itself (UPM).
- `Assets/` — dev host project with the **Demo** sample imported under
  `Assets/Samples/Code Inspector/0.1.0/Demo`.
- `Packages/com.denid.codeinspector/Samples~/Demo` — the sample source
  (identical copy).

See the [package README](Packages/com.denid.codeinspector/README.md) for
features, views, tweaking, live view and limitations.
